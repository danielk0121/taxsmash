# 기술 스택 선정 및 프로젝트 초기화

## 개요
현재 기획서와 슈도코드만 존재하며, 실제 구현을 위한 기술 스택이 확정되지 않았습니다. 사용자의 주력 언어인 Java를 기반으로 할지, 다른 언어를 사용할지 결정하고 프로젝트 뼈대를 구성해야 합니다.

## 작업 내용
- 백엔드 언어 및 프레임워크 선정 (예: Java + Spring Boot)
- 빌드 도구 선정 (예: Gradle 또는 Maven)
- 데이터베이스 선정 (예: MySQL, PostgreSQL, H2 등)
- 프로젝트 초기 뼈대 생성 및 의존성 설정
- `.gitignore` 파일 최적화 (선정된 스택에 맞게 수정)

## 산출물
- 확정된 기술 스택 문서
- 초기화된 프로젝트 코드 베이스

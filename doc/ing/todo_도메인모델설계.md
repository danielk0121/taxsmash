# 도메인 모델 및 데이터베이스 스키마 설계

## 개요
기획서의 '핵심 도메인 용어 사전'을 바탕으로 실제 코드에서 사용할 엔티티(Entity)와 데이터베이스 테이블을 설계해야 합니다.

## 작업 내용
- 주체(근로자, 사업자) 모델 설계
- 매출 및 지출 내역 모델 설계
- 세금 계산 결과(소득금액, 과세표준, 산출세액 등) 저장 모델 설계
- 각 엔티티 간의 연관 관계(Relationship) 정의
- 데이터베이스 스키마(DDL) 작성

## 산출물
- 도메인 모델 다이어그램 (ERD)
- 엔티티 클래스 코드
- 데이터베이스 생성 스크립트 (SQL)

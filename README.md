# taxsmash

개인 소득세 및 부가가치세 통합 정산 시스템 (v1.0)

복잡한 세법의 서술형 규정을 **논리적 계산 엔진**으로 변환하는 것을 목표로 합니다. 사용자의 직업 형태(근로자/사업자)와 지출 성격에 따라 비용 인정 방식을 자동으로 분기하고, 부가가치세와 종합소득세를 명확히 분리하여 최종 납부 세액을 산출합니다.

## 핵심 개념

- **공급대가 / 공급가액 / 부가가치세** — 결제금액에서 부가세를 분리하여 순수 매출액을 추출
- **필요경비 / 소득금액 / 과세표준** — 매출에서 경비·공제를 차례로 차감해 세율 적용 대상 산출
- **세액공제 / 결정세액 / 지방소득세** — 산출세액에서 공제 후 국세·지방세를 명시적으로 분리

용어 정의는 `doc/ing/research_기획서초안.md` 의 도메인 용어 사전을 참고합니다.

## 주요 요구사항

- REQ-01: 부가가치세 전처리 및 분리 (매출/매입에서 부가세 발라내기)
- REQ-02: 주체별 경비 인정 분기 (근로자=정률공제, 사업자=실제증빙)
- REQ-03: 과세표준 산출 및 누진세율 적용 (결손금은 조기 종료)
- REQ-04: 동적 세액공제 모듈 연동 (자녀/월세/보험료 등)
- REQ-05: 국세와 지방세의 명시적 분리 합산

## 시스템 구성 (슈도코드 기준)

- 모듈 1: 부가가치세 전처리 (데이터 정제)
- 모듈 2: 개인 소득세 메인 엔진
- 모듈 3: 경비 및 공제 세부 로직
- 모듈 4: 지방소득세 합산 로직
- 모듈 5: 부가가치세 정산 (매출세액 - 매입세액)

상세 슈도코드는 `doc/ing/research_슈더코드_샘플.md` 참고.

## 향후 확장 계획 (v2.0)

- 법인 모듈 (단일/이중 세율, 대표이사 급여·배당 분리)

- 결손금 이월 모듈 (전년 적자를 차년도 소득에서 차감)

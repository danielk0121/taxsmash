# 개인 소득세 메인 엔진 구현

## 개요
슈도코드의 `[모듈 2] 개인 소득세 메인 엔진` 부분을 실제 코드로 구현합니다. 소득금액 산출부터 최종 납부액 결정까지의 전체 흐름을 제어합니다.

## 작업 내용
- `f세금_계산_프로세스` 메인 함수 구현
- 과세표준 0 이하 시 조기 종료(Early Return) 로직 구현
- 누진세율 적용 엔진(`f세율_적용_엔진`) 구현 (세율 구간 테이블 연동)
- 결정세액 0 이하 시 조기 종료 로직 구현
- 각 단계별 단위 테스트 작성

## 산출물
- 소득세 계산 메인 서비스 클래스
- 누진세율 계산 유틸리티 클래스
- 관련 단위 테스트 코드

# 경비 및 공제 세부 로직 구현

## 개요
슈도코드의 `[모듈 3] 경비 및 공제 세부 로직` 부분을 실제 코드로 구현합니다. 근로자와 사업자의 경비 인정 방식을 분기하고, 다양한 세액공제 항목을 계산합니다.

## 작업 내용
- `f경비_인정_프로세스` 구현 (근로자 정률공제 vs 사업자 실제증빙 분기)
- 근로소득공제 정률 계산 로직 구현
- 사업자 지출 내역의 업무 연관성 검증 로직 구현
- `f세액공제_계산_프로세스` 구현 (자녀, 월세, 보험료 등 동적 계산)
- 각 분기 및 공제 항목별 단위 테스트 작성

## 산출물
- 경비 계산 서비스 클래스
- 세액공제 계산 서비스 클래스
- 관련 단위 테스트 코드
